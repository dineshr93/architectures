# All Properties • Black Duck Detect

Source: https://docs.blackduck.com/r/detect/latest/black-duck-detect/all-properties.html

This page lists all Black Duck® Detect properties, including advanced configuration and those properties that have been deprecated.
For most use cases, refer to [basic properties](https://docs.blackduck.com/r/834deLimBke9_ockudDDwg/GAaQRGIal_nhXfquJomVeQ).
